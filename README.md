# Matthews Global Dashboard - Agentic OS Command Center

A high-performance, real-time executive command center built on the **ARMS (Applications, Routines, Memory, Skills)** framework inspired by the Agentic OS standard.

![Dashboard Preview](https://images.unsplash.com/photo-1551288049-bebda4e38f71?auto=format&fit=crop&w=1200&q=80)

## 🌟 Features
- **❖ Central Artifact & Activity Ring**: Multi-layered SVG/Canvas radial visualizer for daily generated artifacts, routines, skills, and memory routers.
- **🔨 Family Work & Projects Activity Hub**: Real-time progress trackers, checklists, and activity feeds for:
  - **Outdoor Cedar Deck & Pergola** (78%)
  - **Master Ensuite Bathroom Renovation** (62%)
  - **Precision Workshop & Tool Lab** (88%)
- **🛡️ Live DMCA.com Website Sentinel**: Real-time latency sparklines, TLS 1.3 certificate monitor, DNS resolution metrics, and on-demand deep audits.
- **👨‍👩‍👧‍👦 Family & 🐾 Feline Mesh**: Personalized telemetry nodes with uploaded photo avatars for Brillianna, Aurora, Matthison, Ryker, Linda, Laura, plus Jax, Atom, and Mau.
- **🏔️ Meteorological Telemetry & 📹 Whistler Live Cameras**: Real-time Open-Meteo alpine data & multi-camera live feeds from Whistler Peak, Roundhouse Lodge, Village Gondola, and Highway 99.
- **📊 Executive Productivity Hub**: VIP AI-triaged inbox, Kanban tasks & routines, daily calendar agenda, top stock tickers (NVDA, AAPL, GOOGL, MSFT, TSLA, BTC, ETH), and tech news.
- **🤖 Interactive AI Copilot Terminal**: Slide-out command drawer with Web Audio API procedural sound synthesizer.
